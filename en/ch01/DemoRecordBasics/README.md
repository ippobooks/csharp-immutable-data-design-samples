# Record and with expression basics

Uses the simplified `Order` from Section 1.3 to demonstrate creating a
positional record and using `with` to create a new version.

Prints the original and new order states and totals, and whether they are
the same object. A commented-out assignment shows the compile error that
results from modifying `Status` directly after initialization.

Requires the .NET 10 SDK. Run from this directory:

```shell
dotnet run
```
